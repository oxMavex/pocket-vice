- Промпт владельца: «A · Clockwork Block».

### Мини-спека
- Механика: процедурный квартал по seed; у каждого жителя суточное расписание (дом → работа → обед → вечер → дом, плюс пенсионеры, собачники, бариста, ночная смена). Позиция = чистая функция времени, поэтому `__seek(t)` детерминирован.
- Первые 10 сек игрока: видит идущий таймлапс суток, тапает человечка → его маршрут за день рисуется линией, карточка с таймлайном 24ч и «с кем пересёкся сегодня».
- Первый кадр: 7:00 утра, утренний поток людей по тротуарам, тилт-шифт миниатюра.
- Вау: тап → маршрут всего дня одного человека прорисовывается через весь город + подсветка всех, с кем он пересёкся.
- Палитра: тёплый крем/терракота, шалфейный зелёный, сланцевый серо-синий для офисов; акцент коралловый #ff5a36 только для выбранного. Ночь — тёплые окна, без неона.
- Движок: three.js r128 (cdnjs), InstancedMesh для зданий/людей/деревьев, свой tilt-shift шейдер, `preserveDrawingBuffer: true`.
